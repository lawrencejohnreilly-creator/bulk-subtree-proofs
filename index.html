Bulk subtree consistency proofs, actually run

A working implementation of the construction in the draft, checked against direct recomputation of the Merkle tree. Change the parameters and the proof is generated and verified in the browser — nothing is precomputed.

What running it found

The construction as published in -00 does not verify. Its §3.2 laminarity argument assumes every active landmark subtree is a node of the reference checkpoint's tree. Partial subtrees are not: per MTC §4.2, a partial subtree is contained in MTH(D_n) only when n == end. [8,13) is a node at n=13 and does not exist at n=14.

This page runs a corrected construction that tiles the log with full subtrees at landmark boundaries and verifies by descent. That one holds — but it is larger than -00 claimed. Toggle the tree below to see partial subtrees that align to no node.
